# AES：用实验判断自动评分的适用边界

## 问题与我的职责

自动作文评分可以降低人工评分成本，但“能区分作文相对水平”和“给出接近人工的分数”是两个不同目标。这是课程研究项目的公开整理版，并非已上线的评分产品。我独立完成 Part 1 的数据核查、特征模型、LLM 实验、评估与分析，目标是用可核查的数据判断不同方案的表现及局限。

## 实验与方案取舍

| 决策 | 做法与原因 |
| --- | --- |
| 先建立可解释、无需 API 的比较基线 | 在官方 3,911 篇训练作文上训练两组线性回归特征模型，并在全部 2,571 篇官方测试作文上评估。这样先获得覆盖完整测试集、可低成本复现的参照。 |
| 控制 LLM 实验范围 | 对官方测试集中的同一批分层抽样 60 篇作文，比较 3 个模型 × 2 种提示词 × 2 个温度，共 12 种条件；所有条件均返回 60 个分数。API 实验规模与成本边界在 [README](../README.md) 中说明。 |
| 只在相同作文上比较模型 | 对这 60 篇同时计算两组特征模型和 LLM 的指标。完整测试集结果只用于说明特征模型自身表现，不与 60 篇的 LLM 数值直接排名。 |
| 同时看排序与绝对误差 | 历史实验按 Pearson 相关系数优先、MSE 作平局裁决来选出一个 LLM 条件；分析阶段再检查 MSE、MAE、平均误差及高分作文误差，避免把“相关性较高”误读成“分数更准确”。 |

## 结果如何影响判断

在完整的 2,571 篇官方测试集上，扩展特征模型的 Pearson r 为 **0.4996**，MSE 为 **0.2918**。以下是**同一批 60 篇**作文上的对照，不与完整测试集指标混用：

| 方案 | Pearson r | MSE | MAE | 平均误差（预测 − 人工） |
| --- | ---: | ---: | ---: | ---: |
| 基础特征回归 | 0.4533 | 0.2838 | 0.4346 | −0.0027 |
| 扩展特征回归 | 0.5123 | 0.2631 | 0.4144 | −0.0052 |
| 选出的 DeepSeek V3.2 条件 | **0.6616** | 0.4125 | 0.5250 | −0.4583 |

LLM 在这批作文上的相关系数更高，说明它更能跟随相对排序；但它的绝对误差更大，60 篇中有 43 篇低于人工分数。对人工评分为 4.0 或 4.5 的 10 篇作文，平均低估 **1.00 分**。我的结论是：这一条件可继续作为研究候选，不能据此作为无需人工复核的高风险评分方案。完整条件与聚合指标见 [结果摘要](../results/summary.json)，图表见 [结果目录](../results/)。

## 验证、复现与边界

[无 API 特征模型脚本](../scripts/run_feature_models.py)可从官方来源下载数据，核对固定 SHA-256，并重算完整测试集指标；[notebook](../notebooks/aes_part1.ipynb)记录 LLM 实验流程，[离线测试](../tests/test_llm_contract.py)检查请求与分数解析。公开仓库不再分发作文原文、逐行预测和包含作文文本的 notebook 输出。

LLM 条件是在同一批 60 篇作文上选出并报告结果，因此这不是独立留出集上的无偏性能估计。公开整理时没有重新运行付费的完整 LLM 实验，也没有验证跨题目泛化、群体公平性、线上延迟或持续成本。若要走向实际应用，下一步应先设立独立评估集，检查校准和分组误差，并保留人工复核。这个项目的交付是研究流程与决策依据，不是生产评分服务。
